Ridge Runner is a pseudo-3D chase-view flight game set in a procedural dawn canyon. You fly a small aircraft down a winding valley, banking through ten glowing target rings that score points and refuel you, watching your lit artificial horizon, airspeed and altimeter dials, and then you put it down on the valley runway for a landing bonus. One wrong touch of the canyon wall ends the flight.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — arrows steer, W/S work the throttle, Space starts and pauses, R restarts.
